# T6：跨领域可复用性的覆盖与操作化建议

本文件为结果运行前的可行性与定义说明。已执行的程序只计算代码、词形及来源覆盖；尚未计算任何领域的相对性别指标、跨领域相关、回归、置换或效应量。后续分析须以另行单独提交的补充计划为准。本文件不把覆盖数量充足等同于关联模型可识别。

## 固定资料范围与覆盖

保留旧版已选的 `Language_ID`，不按非兄弟姐妹资料重新选择同一 Glottocode 的其他 ID。覆盖分为原 `selected_languages_structural.csv` 的1110个资料ID、既有主样本939个系统、T1严格兄弟姐妹样本625个系统。后续划分指标的建议样本为625个严格系统与各非兄弟姐妹领域的完整单词形系统交集。

词形只取既有 `Form`，按原规则作NFC与连续空白规范化，排除空、`?`、`-`；同ID同目标编码的有效词形取集合，集合大小须恰为1。重复原始行不增加词形数，`Value`、`Form`、`Comment`、`Source`均保留。来源字段只按分号拆分、去除方括号定位；另报全域每格均获同一来源键支持的敏感性样本。不能拼接其他ID、不能把无ego前缀的代码复制至m/f、不能把年长／年幼编码的并集冒充generic类别。

|固定领域|坐标及编码|strict625内完整／完整单词形|单词形谱系数|至少2个配对系统的谱系|单词形且全域同来源|
|---|---|---:|---:|---:|---:|
|堂表亲16格|s×p×c×r；m/f + F/M + B/Z + S/D|254／192|43|14|186|

堂表亲保留男／女ego、父／母侧、中介父母同胞为兄弟／姐妹、堂表亲男／女四个维度。父母同胞16格的长幼是所指者相对其父／母同胞的年龄，即相对ego之父或母；它与兄弟姐妹领域“所指者相对ego年长／年幼”具有不同语义，变量专门命名为 `a_parent`。8格generic领域直接使用已存在的相应参数。

建议以堂表亲16格为优先跨领域检验，长幼父母同胞16格为另一个预先定义的领域，generic8格单列敏感性。该优先次序来自理论领域及覆盖，尚未查看领域结构或任何跨域关联。是否形成单一主检验或多领域校正族，由另行冻结的补充计划写定。

表中“至少2个配对系统”仅是族内比较的必要条件。条件logit还要求结果在族内变化、预测量有足够变化以及控制后的设计可识别；以上条件现阶段尚未检查。原记录可能把较粗亲属范畴展开到多个细编码，完整覆盖不证明原始来源独立调查了每个细格。

## 坐标、基底与精确描述长度

所有位序由 `results/t6/domain_cell_coding.csv` 明确登记，按列出坐标的二元笛卡尔积排列。s=0/1为男／女ego；r=0/1为男／女referent；p=0/1为父／母侧；c=0/1为中介兄弟／姐妹；a_parent=0/1为年长／年幼。兄弟姐妹沿用T1的(s,a,r)位序。

定义q=s XOR r。各领域固定比较如下三种同维度语言：

|领域|L_abs|L_rel_r：保留r、以q替换s|L_rel_s：保留s、以q替换r|
|---|---|---|---|
|兄弟姐妹|{s,a,r}|{q,a,r}|{q,a,s}|
|堂表亲|{s,p,c,r}|{q,p,c,r}|{q,p,c,s}|
|长幼父母同胞|{s,p,a_parent,r}|{q,p,a_parent,r}|{q,p,a_parent,s}|
|generic父母同胞|{s,p,r}|{q,p,r}|{q,p,s}|

最小DNF的含义沿用T1：每个词项块的真值集合必须被若干合取项精确覆盖，不允许覆盖块外单元；每项的成本为正／负文字个数，总成本取最小。划分DL为各词项块最小成本之和；全域单词项块可用空合取，成本为0。可以穷举至多四个特征的全部合取项，再用带权集合覆盖的动态规划求解；不枚举Bell(16)，也不使用近似最简化替代精确值。所有候选语言具有相同特征数，固定λ特征成本在同领域相减时抵消。

堂表亲的p XOR c可描述cross/parallel，而q=s XOR r描述ego与referent的相对性别。二者不是同一个关系。因此绝对基底非合取既可能由cross/parallel等结构产生，也可能来自其他区分，不能独立当作q使用的证据。后续若额外比较含p XOR c的语言，必须在看关联结果前另列为明确规格，不能把它事后吸收到q指标中。

## 至少两种可执行的相对性别指标

对领域d的划分π定义：

1. **建议主要二元指标** `q_advantage_r(π)=I[DL_abs(π)−DL_rel_r(π)>0]`。它表示在固定两套语言的比较中，以q替换s而保留r可节省至少一个文字。它不声称说话者实际使用q，也不把两种语言并列最优算作优势。
2. **连续敏感性指标** `delta_dl_r(π)=DL_abs(π)−DL_rel_r(π)`，保留正、零、负全部取值，不截断负值。兄弟姐妹与其他领域都用相同公式；原始单位均为文字数。若另用按单元数标准化的差，应独立命名并在补充计划写明，不替换原差。
3. **更严格的结构敏感性指标** `q_rescue_r(π)=I[not conjunction_abs(π) and conjunction_rel_r(π)]`，要求每个词项块在相对语言下均为单一合取式，且绝对语言至少一块不是。它可能比第一指标稀少，不能在第一指标阴性后升格为主指标。
4. `abs_nonconj(π)=I[not conjunction_abs(π)]`只作广义结构背景指标。另以同样公式独立计算`q_advantage_s`、`delta_dl_s`、`q_rescue_s`，明确保留哪一个绝对性别坐标，不以两套相对语言中表现较佳者事后择优。

建议主关联使用兄弟姐妹的`q_advantage_r`为X、目标领域的`q_advantage_r`为Y；连续差与rescue指标为预列敏感性。每种指标均先固定定义，再检查能否估计，不因零频、完全分离或结果不支持关联而替换定义。

## 谱系与类别数控制的建议

两领域各自类别数分别为`k_sibling`和`k_domain`。建议主要模型为按`family_group`分层的条件logit：

`logit P(Y_i=1)=α_family(i)+β X_i+γ k_sibling,i+η k_domain,i`。

两个k均预先按线性连续量纳入，不用结果选择变换或删去控制。条件似然消去固定的谱系截距，估计β来自族内比较。没有结果变化的族不会贡献条件似然；预测或控制设计在族内无变化、共线、完全分离或未收敛时均报告不可估计，不靠惩罚或删除控制制造有限效应。若报告一般logit的谱系聚类稳健区间，须清楚说明它仅调整标准误，并没有控制共享谱系造成的混淆，不能取代上述族内估计。

置换建议严格限制在`(family_group,k_sibling,k_domain)`相同的层内置换X，Y及两个k固定，事先固定5000次与SEED=20261016。这对应给定谱系及两个类别数层内的交换性零假设；不是任意历史因果检验。有效层必须有至少两个系统且X存在变化；若所有层的置换均不能改变X，报告置换不可识别。使用较宽的仅谱系内置换会改变与k的条件关系，不能同时称为“已控制两个类别数”的精确置换。可另列较宽零假设的敏感性，但必须在结果前固定并单独命名。

补充计划还需明确主领域／多重校正族、模型收敛规则、效应量区间、置换统计量及失败处理。建议报告OR与区间以及实际贡献族数；不要把名义覆盖族数当作有效族数。族内估计及精确分层置换若信息不足，就如实记NA，不借数据库外猜测补充词形或历史树。
