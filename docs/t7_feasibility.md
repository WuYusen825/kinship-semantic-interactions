# T7谱系分析可行性与本轮决定

用户已授权自主处理决策点。本报告完成输入核查，不拟合Mk，不产生或筛选AIC。

固定版本Glottolog含246棵分类树；文件明确标作classification。全部13288个已写枝长均为1，Tree_Branch_Length_Unit全缺失。`:1`是分类边的单位编码，不是已测年代。

严格样本为625系统、108谱系组。暂拟“合取/非合取×k的1–2、3–4、5–8层”最多六态：{'合取_3–4': 323, '合取_1–2': 214, '合取_5–8': 66, '非合取_3–4': 10, '非合取_1–2': 7, '非合取_5–8': 5}。其中非合取仅22系统，可能造成多态全异速率参数极不稳定。至少10系统且含非合取的谱系组共6个；完整覆盖含内部节点匹配数见results/t7/family_coverage.csv。

## 可行近似与后续设计

单位枝长及Grafen枝长均可构造，后者可预设ρ=.5/1/2。应分别修剪到真实采样语言、保留多分叉、处理被采语言同时是内部节点的情形，并在六态过稀时采用事先固定的二态方案；根状态固定为平稳或自由参数需事先选择。近似所得速率只以人为树尺度计量。

## 本轮决定

本轮不运行可选Mk：现有固定输入无法提供可靠演化时间，且稀有非合取状态使多态速率缺乏信息。第三版只把历史传承作为由文献支持、尚待本数据直接检验的解释，不能以本可行性报告支持方向性转移结论。若Claude决定继续近似Mk，须将其明确标为拓扑假设下的探索性敏感性；更优路径是先取得可追溯时间标定树及其不确定性样本，再执行ER/ARD/转入非合取受限模型比较。
