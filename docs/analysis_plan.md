# 第三版新增分析计划

## 地位与执行门

本计划写于原分析、S1、S2及第二版理论讨论已知之后。以下任务称“预先设定的补充分析”，该称谓仅表示本文件在本轮T2–T7实测前提交，不表示事先未知所有相关现象。未列分析另标“探索性”。不得根据新结果改变主指标、删去模型或缩小样本。

先执行T0；任何计数不符、损失误差超过1e-4或指定区间超过2e-3即停止汇报。T0通过后保存报告并建立`baseline-v1`。T1建库和测试通过后才运行T2–T5。本文件必须先独立提交，其提交及SHA写入入口核验。T6/T7只做可行性与操作化报告，未经用户确认不做关联或转移结果分析。

全部新随机计算使用SEED=20261016，整谱系bootstrap为5000次。保存全部尝试，包括失败、阴性及敏感性；未收敛拟合不作推断。`results/run_log.csv`追加时间、任务、完整规格、主要指标、收敛及git提交。现有冻结文件及第二版保留。

## 数据、坐标及权重

严格样本为每个位置只有一个规范化词形的完整八类系统，共625系统、108谱系组。主样本939系统、125谱系组，各28类别对。输入和数据版本沿用`docs/repo_map.md`，八位置按`docs/cell_coding.md`对齐。s/a/r的0依次表示男性参照者/年长/男性所指者，q=s XOR r，0为同性。划分使用RGS规范编码，枚举全部4140个划分。

不改变旧P2/P3/P4：调用`strict_prediction_directions`返回predicted_side=+1、opposite_side=−1、not_applicable=0。新的年龄区分配置集合另命名，不把它当作旧严格层级方向。

谱系等权：每个训练谱系总权相同，谱系内每个系统等权；对数似然评分先求谱系内系统均值，再求谱系均值。对类别对模型保持现有`row_weights`数值尺度，系统28对权重相等。语言等权：系统等权；严格样本每系统一行，因此语言等权与无权在划分模型中数学相同，两标签均报告，避免伪装为独立敏感性。

主外层五折沿用939样本既有谱系折号，严格样本及子样本仅取子集，不重新平衡；语言五折也沿用旧映射。留一宏观区域使用首个已记录宏观区域，缺失者仅从地域验证排除。内层为训练集内三折谱系分组；不使用外层测试结果选择基底、惩罚或模型。

## T1：划分与描述语言

对每个非空子集，穷举每特征取0、1或省略的全部合取项，保留非空外延及最低文字成本。在目标子集内用精确集合覆盖动态规划，求并集恰为该子集的DNF最少文字数。真式（八元全集）文字数为0；空集不作为词项。允许合取项重叠，文字数为各项文字数之和，括号、连接符和词项名称不另收费。划分DL为各词项块DL之和；该指标是新增DNF编码，与旧S2分类树边数分别命名。

描述语言为L_abs={s,a,r}；L_rel_r={q,a,r}（任务书主相对基底）；L_rel_s={q,a,s}（旧S2相对坐标，必须同时报告）；L_all={s,a,r,q}。成本DL_total=DL+λd，λ∈{0,1,2,3}，d为整个描述语言的特征数。

固定语言中λd对所有划分相同。进入最大熵分布后常数在归一化时抵消，因此A6的λ扫描应给出相同分布；它不能检验对特征库存成本的偏好。T3可比较不同语言的实际总成本、阈值与排序，二者不混同。

建`results/t1/partitions.parquet`及625系统映射；另保存939系统的集合完全相等划分、共享图连通分量划分。后两者只是敏感性操作化，不等同原D1的非传递共享关系。

验收：4140合法唯一RGS；按r两类在abs下合取；同性/异性二类在abs下非合取且两种rel下合取；观测abs非合取163、all非合取22；与既有合取函数逐划分核对。DNF用独立暴力小子集例子核验精确最优。

## T2：统一划分概率模型

### 假设与阶梯

精确概率P(π)=exp(θφ(π))/Σexp(θφ)，在4140划分上用logsumexp归一化。A0均匀；A1=k,k²；A2=A1+conj_abs；A3r/A3s=A1+conj_rel_r/conj_rel_s；A4=A1+DL_abs；A5r/A5s=A1+DL_rel_r/DL_rel_s；A6(λ)=A1+DL_all+λd；A7=内层选中的A2–A6描述模型+P2+P3+P4。主相对比较为r，s为坐标敏感性；主A7候选包含两种相对坐标。每个外层训练集先以内层OOF选出不含P的最佳基底及α，固定该基底，再以内层OOF为加入P的A7选择α；外层同时评估A7与先前选中基底，不让加P之后的成绩回选另一基底，也不先用外层结果挑选最佳基底。A8可选，本轮不增加交互，避免事后选择。

所有特征按4140理论支持点的均值/标准差中心标准化（与实测结果无关），常数列删除并记录。目标为训练加权平均负对数似然+α||θ||²/2，α∈{0,.01,.1,1}；α由内层谱系三折平均谱系评分选择，内层先合并三折全部OOF预测，再按指定权重评分，不能简单平均折分数。平局（得分差≤1e-10）依次较强惩罚、较少特征列、固定顺序A2/A3r/A3s/A4/A5r/A5s/A6。固定α的A7仍使用本外层训练内先选出的描述基底，只固定其α。精确目标为logsumexp(Φθ)−θ·φbar_w+α||θ||²/2，训练权重先归一。L-BFGS-B使用ftol=1e-12、gtol=1e-8，solver.success、参数及目标有限、归一化误差<1e-9、最大绝对梯度≤1e-6全部通过才算收敛；主尝试最大2000次，若失败同目标同初值增至10000次。α=0另外用理论特征凸包的相对内部可行性检查有限MLE：观测加权特征均值须能由全部唯一支持点的严格正权重表示：线性规划最大化支持点最小概率t，使用primal/dual feasibility tolerance=1e-9，须t>1e-9/m（m为唯一支持点数）；边界/数值无法判定者不冒称有限MLE。仍失败的候选保留状态、内层选择中不可选；固定α相关比较标不可评估，不补换估计器、不删除测试系统。除内层选惩罚主结果外，保存四个固定α外层成绩。

严格625为主，939集合相等与939共享图连通分量为敏感性。每种样本、两权重、三种外层验证均运行模型阶梯；无权与语言等权的恒等另报。保留逐系统折外对数似然、选择结果、逐拟合状态及训练/测试ID。

### 指标、区间和解释

主指标为留出每系统平均log P(π)，nats，越高越好。所有模型相对A0、A1及下述指定比较均给5000次固定折外预测整谱系重抽95%百分位区间。该区间不包含重新训练/划折。Q1比较A3r−A2、A5r−A4（s坐标并列），正增益且区间下界>0支持该指定比较；两种指标不合并成单一已证明结论。

Q2比较嵌套选择的A7与同一外层训练集内选中描述模型的增益。仅对主严格625、谱系等权全样本A7给三个位置系数的5000次整谱系重新拟合区间。Pi的+1为预测侧，预期系数为正；不与旧M4中三个负的pair条件项混同。以全样本内层谱系CV选定的模型/α为条件，逐项及Bonferroni98.333%区间并报；它不包含模型选择不确定性。所有非收敛副本记录，不填补为0、不重抽补足，区间仅在至少95%副本成功时展示，并标成功比例。

Q3从同一外层训练分布求28对共享概率Σπ P(π)I(π_i=π_j)，在625严格样本、相同折和权重下与重拟合M0–M4比较逐系统平均pair logloss。主报告划分模型损失−M2/M4损失及95%区间。不劣界设为0 nats；只有区间上界≤0才称“不劣得到支持”，否则明确证据不足，不以不显著作等价。

Q4用不含显式位置项的描述模型及A7分别导出七差异单元的共享率；对其logit按旧M2七列求系数，并与严格样本M2及全939旧M2并列。报告DrDa、DrDe、DaDe符号、量值、生成与实测系数之差以及七单元内部28对异质性。七单元M2是满秩饱和，任何七个有限logit的投影残差恒为0，故该残差仅作数值核验；解释为给定类型分布是否可产生总体非加性，不把“存在非加性”当作已恢复其全部强度或证明真实混合机制。

全样本拟合分布抽样生成5000个与原样本等大合成样本，给k分布、各基底合取比例、P2–P4预测/相反/不适用比例的预测区间，与实测并列；这是MLE拟合分布的预测检查，不冒称贝叶斯后验。图表保留28对及七种差异，新增图名Fx_开头。

## T3：127特征及对称性

枚举所有非平凡二分，以含0号单元一侧的8位mask作互补去重，共127。每个f加入{s,a,r}，计算理论合取划分数C_f、观测合取数N_f、谱系等权比例和E_f=(N_f/625)/(C_f/4140)。q已知N_q应为603，这是定义核查，不是新假设。排名同时给N、C、E并列名次，不挑一个有利排名。

随机参照沿用旧S2固定词项数及块大小：每个系统从该shape全部理论划分均匀抽取，合取概率由精确枚举给出。5000次独立生成的整样本计数形成随机参照分布；其区间为条件随机参照预测区间，不混称谱系bootstrap置信区间。另对观测系统/谱系比例做5000次整谱系bootstrap。图x=C/4140、y=N/625，标s/a/r/q及富集最高者。

全局性别互换T:(s,a,r)→(1−s,a,1−r)。分别计数f(Tx)=f(x)的特征（预期7个互补去重）与f(Tx)=1−f(x)的标签互换二分；仅前者可称特征值不随性别标签交换而改变，不把无标签二分的额外情况删除。

T3c报告四语言两权重的平均DL+λd及整谱系区间，全部λ和排序/交点均保留。相对基底若仅优于某一基底或富集排名并非最高，照实限定理论结论。

## T4：相对配置与标记性的直接对照

新函数`age_distinction_set`返回A⊆{MM,MF,FM,FF}，首字母为ego、次为referent；同配置长幼类不同时记入。`gender_distinction_set`返回G⊆{ME,MY,FE,FY}，指固定ego与长幼时男女所指者不同类。偏性为0<集合大小<4。列全14种A及G类型频率。

四项年龄对照：(i)非空A⊆{MM,FF}对非空A⊆{MF,FM}；(ii)A恰为{MM}对恰为{FF}；(iii)恰为{FM}对恰为{MF}；(iv)非空A⊆{MM,FM}对非空A⊆{MF,FF}。两侧均不符的系统不进该项分母，保留排除数；i与iv之间可重用系统，但同一对照内不重计。ii的等价差为p_MM−p_FF=2p_MM−1，边界固定±0.15，使用5000次整谱系重抽95%区间，完整落入边界才称支持等价。分母不足/重抽空分母单列，不以零差或非显著推断相当。

系统级精确双侧二项检验，并报告方向。谱系级先在该对照符合任一侧的系统中取两侧多数，平局单列不进分母，沿用旧方向聚合方式。为回应“多数类型”的歧义，另命名`family_modal_partial_type`：先在谱系内全部partial A的14种精确类型中取唯一众数，再将该类型投入四对照；多众数或不符合两侧单列。两个谱系口径不混合，主表使用对照内方向多数，与旧稿衔接。等价检验主量为方向多数谱系差δ=(G_MM−G_FF)/(G_MM+G_FF)，在已确定多数的相关谱系中整谱系重抽；另给系统差和按相关谱系内系统比例均值计算的连续谱系等权差，明确是不同敏感性。谱系样本数最多108、相关子集更小，±.15边界可能难以确立等价；不因能力有限或区间过宽放宽边界，结论不越过对应估计对象。

D2分别对male/female ego计算年长与年幼的性别区分，两边不一致者进入年长vs年幼二项检验。四项A和两项D2合为六个预先设定对照；系统与谱系口径各自对这六项作Holm校正，不把等价区间当作二项检验的替代。分别移除Austronesian、Pama-Nyungan后重算；按宏观地域给计数和方向。两种理论都不能从数据库非独立系统直接推断心理因果。

## T5：原类别对分析的修订

5a：重算D1/MLE/family权重、留一宏观区域M0–M4的逐对预测。逐区域报告实测共享率、平均预测率、原始loss、固定斜率仅拟合一个截距偏移后的loss、谱系等权AUC；另报区域宏平均。截距由留出区域真实结果拟合，因此明确标为事后校准诊断，不能作为真正未见区域预测分数。AUC只有正负结果都存在时才计算。是否可称“结构可迁移、基准率不同”须同时有校准诊断与排序证据，不能因loss改善机械断言斜率普遍稳定。

5b：D1全样本M0–M4保持旧训练尺度，计算谱系聚类稳健协方差及95%区间，M4三条件项与旧5000重拟合区间并列。只有谱系随机截距的BinomialBayesMixedGLM作未加权模型敏感性，固定效应N(0,2²)、log随机标准差N(0,.5²)，固定初值零、sd exp(−.5)，BFGS最多2000、梯度1e-6，失败同设置增至10000一次；输出收敛及梯度，只有通过者进入推断表。该VB近似不是频率学GLMM精确MLE，表述区分。不运行旧未收敛的谱系×区域交叉模型。
