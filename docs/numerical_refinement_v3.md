# T2数值求解精化附录

## 调整时点与触发

本附录写于严格625、谱系等权、谱系五折的首次T2计算之后，其他规格与系数bootstrap尚未完成。首次原计划解法的输出另存保留，不回写为成功。触发问题为L-BFGS-B先因ftol=1e-12停止，虽solver.success=True，实际最大梯度约1.1e-6至1.4e-5，未过原定1e-6门；只增大迭代上限的同初值重试会重复同一提前终止。

## 唯一新增步骤

原两次拟合仍完整记录。在同一目标、理论支持点、样本、训练权重、标准化、α、零初值及L-BFGS-B方法下，若仅数值收敛失败，增加一次ftol=1e-15、gtol=1e-8、maxiter=10000、maxls=50的求解。保留原来的solver.success、有限目标参数、最大绝对梯度≤1e-6和概率归一误差<1e-9全部收敛条件；不放宽阈值。α=0的有限MLE边界失败不靠此步骤绕过。

本步骤适用于全部模型及全部规格，不因效应方向选择性重试。仍不收敛的拟合保留NA，不删除测试系统、不替换估计器。嵌套基底/α选择在相同外层训练内重新按合格拟合执行，全部选择规则保持原定。

## 报告方式

此次调整是运行后明确追加的数值精化，不能声称原冻结计划包含此步骤，也不改变已预先设定的科学模型或评价指标。首次NA结果与精化结果分目录保留，在结果报告及Claude矛盾文档说明。独立审查应核对实际梯度、归一、目标值与全部尝试，不能仅凭优化器返回码接受。
