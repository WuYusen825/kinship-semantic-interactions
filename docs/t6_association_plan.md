# T6跨领域关联：运行前补充规格

本文件写于覆盖与编码可行性报告之后、任何T6结构指标或关联结果之前。用户授权自行处理决策点；本分析全部为探索性，不称验证性。可行性与操作化以`docs/t6_operationalization.md`为准。

## 领域与指标

两个预列主领域为堂表亲16格、长幼父母同胞16格；generic父母同胞8格为敏感性。各域只在既有625严格兄弟姐妹系统与该域完整单词形系统的交集，不改变已选Language_ID，不补格；另在跨域全格同来源的子集中重复主分析，标来源敏感性。三种领域的明确坐标与词形规则不改。

主X为兄弟姐妹`I(DL_abs−DL_rel_r>0)`，主Y为目标域同指标；rel_r以q=s XOR r替换s并保留r和其余坐标。精确DNF由通用有限集合覆盖求解，不近似求最简、不得把cross/parallel的p XOR c叫q。另完整输出连续delta_dl_r、q_rescue_r、abs_nonconj和rel_s各对应指标，作为预列描述性敏感性：保留逐系统取值与频数，不在阴性后换成主结果，也不再从这些指标中挑选新的主回归。

## 主模型、权重与估计门

主模型为`logit P(Y=1)=α_family+βX+γ k_sibling+η k_domain`，两个k固定为线性连续控制。条件似然消去谱系截距。训练延续谱系等权：各谱系的条件loglik除以该谱系配对系统数，再对有效谱系取平均；相应梯度和Hessian按同样权重计算。无结果变化的谱系不贡献条件似然，全部列出；不得把名义覆盖谱系数当作信息谱系数。

先对族内中心化的[X,k_sibling,k_domain]检查秩为3。再用所有同族case-control差向量D检查分离：在Db≥0、b各分量∈[−1,1]下最大化ΣDb；最优>1e-9即完全/准分离，没有有限MLE，报告NA，不以惩罚或删k制造效应。

调用statsmodels的条件loglik及score/score_grp，用scipy.optimize.minimize直接BFGS求同一加权平均目标，以避免fit包装丢失gtol与优化状态。零初值、gtol=1e-8、maxiter=2000，失败仅同初值同目标增至10000一次。接受须solver.success、参数/目标/score/H均有限、平均目标max|gradient|≤1e-7、负H正定、condition≤1e12；否则保留失败诊断，不推断。不得以仅返回参数当作收敛。

对合格模型，以加权族score S_g及加权负H的逆计算CR1 sandwich：G/(G−1)·Hinv·ΣS_gS_g'·Hinv。G为实际贡献族数，至少2；SE须有限且>0。报告β、OR、t(G−1)的95%区间、实际系统及贡献族数。两个16格领域β的双侧t检验为一个Holm2校正族；某项不可估计也保留m=2。

另给谱系等权的一般logit及聚类稳健区间作为预列敏感性。该模型只调整依赖标准误，没有消去谱系截距，不能替代主条件模型。一般logit须无分离、设计满秩及相同梯度/有限H收敛门；失败不改估计器。其两主领域p另作Holm2，不将其有利结果替换主模型。

## 精确分层置换

层h固定为(family_group,k_sibling,k_domain)。统计T=Σ_hΣ_i(X_i−Xbar_h)(Y_i−Ybar_h)，层内保持Y和两个k，仅洗牌X；5000次，SEED=20261016。双侧p=(1+#(|Tperm|≥|Tobs|))/5001，两主领域置换p另作Holm2。

此统计与条件logitβ并非相同估计对象；它对应给定谱系与两个类别数层的交换性零假设。若没有n≥2且X、Y均变化的有效层，置换不可识别，记NA，不返回p=1冒充有信息。完整列有效层、有效系统与不同置换统计量数量，不把5000重抽次数当作独立信息量。8格及同来源分析单列敏感性，不并入主校正族或挑选显著项。

## 运行与保存

`analysis/v3/cross_domain.py`从已锁输入构造指标，输出`results/t6/association_results.json`、逐系统指标、模型与置换诊断及中文报告。入口核对本文件独立提交及SHA早于运行；结果追加run_log。无可估计模型仍完整报告NA、原因与描述指标，不扩大样本或改定义；第三版据此限定关系表征的跨领域可复用性。
