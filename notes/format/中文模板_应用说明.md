# 中文格式模板的应用

本文件说明如何使用用户提供的[中文格式模板](中文格式模板.docx)：模板仅用于字体、行距与引用格式。用户随后另行要求扩展正文并深化理论讨论，内容修订依据该指示执行，不从模板复制。原始模板保持原字节，实际段落属性及其继承关系保存在[格式规则](中文模板_格式规则.json)。模板中的示例题名、章节名称和无关文献不进入论文。

|位置|字体与字号|行距|
|---|---|---|
|中文题名|宋体20磅，不加粗|1.5倍|
|作者与学校|仿宋11磅|1.5倍|
|摘要、关键词|宋体10.5磅，标签按模板加粗|1.5倍|
|正文|宋体12磅；西文Times New Roman|1.5倍|
|章节标题|宋体12磅，加粗|1.5倍|
|文末参考文献|Times New Roman12磅，中文宋体；悬挂24磅|1.5倍|

摘要、关键词没有直接字号，实际继承模板Normal样式的10.5磅。模板未提供二三级标题、图表、英文副标题和页码的示例；二三级标题沿用正文12磅并加粗，图表、英文副标题和页码保留原字号。纸张、页边距、表格尺寸、正文缩进和段前段后间距保留正式稿原设置；没有复制模板的空白段落或作者信息排列。

英文文末书目依模板示例采用自然大小写姓氏与带点姓名缩写、末位作者前的“&”、括号年份、斜体刊名和DOI网址。全部作者依现存可核元数据列出，书章和会议论文保留各自文献类型所需信息；具体条目与缺项说明见[参考文献记录](../formal_references.md)。模板书目兼有不同惯例，不将其宣称为严格APA第7版。模板没有正文引注示例，正式稿原有的著者—出版年与核实页码上标保持。

Word使用模板要求的宋体、仿宋与Times New Roman字体名。当前环境没有这些字体文件，PDF作为预览，中文以Noto Serif CJK SC代排，西文以Liberation Serif代排；仿宋也由Noto Serif CJK SC代排，其字形与模板原字体存在差异。需要原字体效果时，在已安装模板字体的Word环境中打开DOCX并另存PDF。

重建正式稿：

```bash
python analysis/export_forum_documents.py --input outputs/论文_中文正式稿.md --name 论文_中文正式稿 --abstract-name 正式论文_摘要 --page-numbers --format-profile notes/format/中文模板_格式规则.json
```

本次不重新估计统计模型。格式前材料保留在`notes/formal_format_revision_20261016/`，随后理论扩写另存基线与[证据台账](../discussion_expansion_20261016/research_ledger.md)。独立内容与排版复核按扩写后的最终SHA记录；此前正式稿独立评审仍对应原来的快照。
