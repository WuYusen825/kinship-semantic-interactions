# 独立方法审计：兄弟姐妹差异空间、模型含义与推断单位

## 审计范围与基础

本记录独立核查兄弟姐妹八类别设计的代数结构，审阅已冻结的分析协议及结果前补充协议，并在正式结果生成后核对代码与折外预测。对数据分析脚本和结果采用只读审计。

八个类别构成三个二元特征的完整立方体：所指者性别、相对年龄、参照者性别。两种不同类别形成一个无序对；因此每种完整语言有 $\binom{8}{2}=28$ 对。各差异指标按所指者性别、年龄、参照者性别顺序记为 $(D_r,D_a,D_e)$。七种可观测差异为 001、010、011、100、101、110、111；每种差异恰有四个类别对。000 在不同类别的配对中不存在。

## 设计矩阵的精确核验

使用整数设计矩阵与 SymPy 精确代数，核验得到：

| 设计 | 列 | 秩 |
|---|---:|---:|
| 原始加性 | 截距、三个差异主效应 | 4 |
| 经典相对性别加性 | 原始加性、相对性别关系差异 | 5 |
| 两两交互 | 原始加性、三个差异乘积 | 7 |
| 再加三阶交互 | 两两交互、三个差异的乘积 | 7 |

以七行按上述顺序构造两两交互设计矩阵，其行列式等于 −1，故满秩。两两交互模型可为七个差异单元分别给出一个任意 log odds；它是七个差异单元的饱和表示，并未为 28 个具体类别对分别给出任意预测。

在七种非零差异上有恒等式：

$$
D_rD_aD_e=1-D_r-D_a-D_e+D_rD_a+D_rD_e+D_aD_e.
$$

因此三阶交互不能与截距、三个主效应及三个两两交互分开估计。观察到七单元非加性并不能确定产生该分布的机制只含二阶交互。

二维四类别体系有三种非零差异，每种两对。“截距+两个差异主效应”的秩已经是 3；加入乘积后仍为 3。因此祖辈与父母兄弟姐妹的二维配对用于描述性核验，不提供独立的两阶交互检验。

## 经典相对性别区分与交互的关系

对类别 $i$ 定义所指者与参照者是否异性 $q_i=r_i\oplus e_i$。两个类别在该区分上的差异满足：

$$
D_q=q_i\oplus q_j=(r_i\oplus r_j)\oplus(e_i\oplus e_j)
     =D_r\oplus D_e=D_r+D_e-2D_rD_e.
$$

故“原始加性+相对性别差异”的五列空间，严格等于“原始加性+所指者性别差异×参照者性别差异”的五列空间。无惩罚最大似然下，它们给出相同可拟合概率。一般岭惩罚不在此参数变换下保持不变；在两种编码上直接给予各系数相同 L2 惩罚会得到不同的有效约束。结果前补充协议已将无惩罚完整样本比较固定为敏感性分析。

从原始加性模型到经典模型增加一个自由度；从经典模型到七单元模型再增加两个自由度。因此论文需要分别报告两种提升，第一种对应传统相对性别区分的重新表达，第二种才考察年龄相关差异能否提供额外预测信息。

## 系数的可解释范围

令 $\eta_{rae}$ 表示每个可观测差异单元的 log odds。在七列满秩模型中，截距为

$$
\beta_0=\eta_{001}+\eta_{010}+\eta_{100}-\eta_{011}-\eta_{101}-\eta_{110}+\eta_{111}.
$$

这是对不存在的 000 单元的外推值，不是同一类别共享词形的实测 log odds。主效应也以这个未观察基线为参数化参照。相反，三个交互可写成完全由已观察单元构成的对比：

$$
\gamma_{ra}=\eta_{111}-\eta_{101}-\eta_{011}+\eta_{001},
$$

$$
\gamma_{re}=\eta_{111}-\eta_{110}-\eta_{011}+\eta_{010},
$$

$$
\gamma_{ae}=\eta_{111}-\eta_{110}-\eta_{101}+\eta_{100}.
$$

依次是在第三个差异为 1 时，另外两个差异形成的矩形对比。正文宜优先报告七个单元的共享概率、样本外损失和这些可观察对比。将显著性或系数符号解释为心理词库或交际机制，需要额外证据。

## 预测验证与区间的实际含义

冻结协议规定固定效应 logistic 回归、按语系五折留出、语言等权主评分。这与语言／语系随机截距模型是不同的实现；论文的方法及结果应按实际实现表述。完整样本每种语言 28 对，语言等权与逐对等权结果相同；至少六类的敏感性样本中两者才可能不同。

同语系组必须在每折整体进入训练或测试。逐对随机拆分无法衡量对新语言的预测。谱系留出检验模型对当前数据库中未见谱系组的预测，仍受地理接触、资料来源分布以及数据库抽样结构影响。

现有折外预测固定后，对语言评分整组重抽语系的区间，表示谱系样本组成变化下的评分差不确定性。它未重训模型，不能视为包含模型估计、折划分与样本组成全部变化的估计量置信区间。协议已清楚限定此范围；正文保持同样表述。

语言内 28 个类别对共享类别节点，存在依赖；独立 Bernoulli 似然用于求预测函数可以称为工作似然或复合目标。普通独立样本系数标准误和以逐对样本量为基础的显著性检验不能直接代替谱系分组验证。

## 词形集合与资料来源

主结果为两类别词形集合交集非空。这个二元关系一般不传递：$A=\{x\}$、$B=\{x,y\}$、$C=\{y\}$ 时，A–B 与 B–C 共享词形，A–C 不共享。因而该结果称为“共享词形网络”或“成对同形关系”，无需把它写成一个类别等价划分。严格词形集合相等的关系则具有传递性。

同一 Glottocode 的多个资料 ID 按覆盖率择一，不跨 ID 合并，保证来源选择未使用结果。已选 ID 内若包含多个来源，词形集合的并集仍可能受来源差异影响；按覆盖择单一来源的敏感性用来量化这一影响。不得把源自原始粗类别展开的八个记录称为八次独立 elicitation。

结构审计的 941 种完整系统包含 918 种已有语系归属、21 种孤立语言以及两个无法用于官方谱系分组的资料：Limilngan-Wulna（未分类）与 Proto-Tupi-Guarani（未联结）。正式样本按协议排除后为 939。数据还含 Latin、Old English、Ancient Greek 等历史系统，研究对象表述为“数据库记录的语言／语言变体亲属称谓系统”更准确。

## 建议的正文措辞

> 本研究首先比较三个独立差异指标的加性预测与七差异单元的非加性预测，再加入传统同／异性关系差异作为理论基准。该传统区分在原始差异编码中与所指者性别×参照者性别交互具有相同的模型空间。由此，预测提升可以拆分为传统相对性别区分所解释的部分，以及年龄相关差异组合提供的剩余部分。

> 两两交互模型在不同类别所产生的七个差异单元上满秩且饱和，但在具体类别对层面仍受“相同差异具有相同预测”的约束。本研究检验的是共享词形概率在规定 log odds 尺度上的加性限制，而非认知机制的交互阶数。

## 总体预测与语言内机制的区别

固定效应合并模型检验本样本总体共享词形概率的加性限制。它没有逐语言估计交互，也没有将语言间异质性与语言内非加性分离。即使各语言的条件 log odds 都是加性的，合并以后的 log odds 仍可能出现非加性。

一个确定性数值例子是：两组等权语言具有截距 −3 与 +3，而三项主效应均为 +1，各组均不含交互。对两组概率先平均，再转换为 log odds，七单元的三个两两交互系数均约为 **0.221072**。这是 logistic 非线性与群体混合产生的统计现象，并非组内存在交互的证明。

因此样本外预测提升支持“总体共享词形分布的非加性”，其是否对应单个语言的语义表征，需要另外的语言层级模型或完整系统生成分析。谱系留出验证衡量对未见谱系组的预测，并不直接解决该层次差异。

## 正式执行结果核验

独立从锁定 Kinbank 的 `Form` 与 `Source` 原始字段重建词形集合及来源集合，并直接读取逐对折外预测重算所有评分，完成以下核验：

| 核验 | 结果 |
|---|---|
| 主样本 | 939 个系统、125 个谱系组、26,292 个无序对 |
| 每语言配对结构 | 均为 28 对；七个差异单元均为四对 |
| 无序对重复 | 0 |
| 独立重建共享结果与保存结果差异 | 0 |
| 独立重建三项差异特征与保存结果差异 | 0 |
| 官方 Glottolog 谱系联结差异 | 0 |
| 八个条件及语言辅助验证中的分组泄漏 | 0 |
| 独立 log loss、Brier、平均增益最大误差 | $2.22\times10^{-16}$ |
| 逐对保存损失最大误差 | $4.44\times10^{-15}$ |
| 重新计算 5,000 次谱系簇区间最大误差 | $3.90\times10^{-17}$ |
| 无惩罚折外交互预测与训练折实测单元率最大差异 | $1.11\times10^{-7}$ |
| 全样本无惩罚交互预测与实测单元率最大差异 | $1.15\times10^{-9}$ |

九组输出的评分与区间均得到数值复现，未发现实现或数值不一致。

### 主比较的证据强度

主条件为谱系五折留出、语言等权、`C=1`。三个模型 log loss 依次为 0.581049、0.578468、0.576625。两两交互相对原始加性的平均增益为 0.004423，谱系簇 95% 区间 [−0.000510, 0.008205]；相对经典加性的增益为 0.001843，区间 [−0.000604, 0.006120]。两项点估计均为正，区间均跨零。

| 条件 | 语言数 | 相对原始加性增益 | 相对经典加性增益 |
|---|---:|---:|---:|
| 主条件 | 939 | 0.004423 | 0.001843 |
| 至少 75% 覆盖 | 997 | 0.004765 | 0.002291 |
| 词形集合完全相同 | 939 | 0.002682 | −0.001972 |
| 每类仅一词形 | 625 | 0.003352 | −0.003427 |
| 单一文献来源 | 911 | 0.004302 | 0.001294 |
| C=0.1 | 939 | −0.000601 | 0.000982 |
| C=10 | 939 | 0.010027 | 0.007135 |
| 无惩罚 | 939 | 0.010437 | 0.007534 |
| 语言留出辅助验证 | 939 | 0.009032 | 0.001548 |

严格集合定义与单词形子样本中的经典剩余增益改变方向，强惩罚条件中的原始增益也改变方向。弱惩罚与无惩罚条件具有较大的正向点估计，其谱系簇区间位于零上方；这些属于事前规定的敏感性结果，不替代主要 `C=1` 比较。总体结论表述为“预测增益的大小与方向依赖操作性定义和正则化程度；主比较呈现小幅正向点估计”，与全部结果一致。

### 岭比较的归因界限

主条件中经典五列与交互七列除了模型空间不同，其惩罚几何也不同。因此主条件的经典剩余增益不宜全部归因于年龄相关交互。无惩罚敏感性消除此参数化惩罚差异：经典五列等同于单一所指性别×参照者性别交互，七列模型额外加入两个年龄相关方向。无惩罚结果可以说明该更明确的模型空间比较，但它仍保留敏感性分析的证据地位。

### 可直接用于论文的结论句

> 在预先固定的语系留出比较中，七差异单元模型取得较低的平均预测损失，但主要谱系簇区间包含零；不同词形定义与正则化强度呈现不同的增益。经典相对性别区分提供了重要的理论基准，年龄相关差异的额外预测价值随分析条件变化。本研究据此展示了亲属共享词形总体分布的非加性表示，以及检验这一表示所需要的编码、来源和模型约束。
