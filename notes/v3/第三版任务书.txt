T1 划分空间与特征库
⽬的：为 T2–T4 提供共⽤基础设施。

实现

1. 枚举 4140 个划分，建表 partitions.parquet （RGS、类别数 k、各单元集合）。
2. 语⾔（language of description）：⽤⼀组⼆值特征描述单元集合。实现下列语⾔，并给
  出"某集合在该语⾔下能否表示为单个合取式"的判定，以及最⼩描述⻓度：
     L_abs = {s, a, r}
       L_rel = {q, a, r}，另做 {q, a, s} 作对照（⼆者是不同的坐标系，结果应同时报告）

       L_all = {s, a, r, q}

      描述⻓度 DL：对单元集合求最⼩ DNF 的⽂字数（⼋个单元、⾄多四个特征，可穷举或
      Quine–McCluskey）。划分的 DL = 各单元 DL 之和。
      语⾔附带特征成本 λ： DL_total = DL + λ · (语⾔特征数) ，λ ∈ {0, 1, 2, 3} 作扫描。

3. 位置特征：对每个划分计算 P2、P3、P4 ∈ {+1（符合预测）, 0（不适⽤）, −1（相反）}，直
  接调⽤仓库中既有的判定函数，不要重写定义。
4. 把论⽂的 625 个系统映射到各⾃的划分编号，输出 systems_to_partition.csv 。

单元测试（必须通过）

  划分总数为 4140；每个划分是合法划分。
  仅按 r 分为两类的划分在 L_abs 下合取。
  "同性 vs 异性"（{MM, FF} 与 {MF, FM}，不分年龄）在 L_abs 下⾮合取，在 L_rel 下合
  取。
  在 L_all 下⾮合取的系统数 = 22；在 L_abs 下 = 163（与 T0 ⼀致）。


T2 划分层⾯概率模型（核⼼）
⽬的：在划分层⾯建⽴统⼀模型，使合取偏好、基底选择、位置不对称与总体共享率出现在同⼀
框架，并通过留出似然⽐较理论。

模型：对 4140 个划分定义条件 logit（最⼤熵）分布

P(π) = exp(θ·φ(π)) / Z ， Z = Σ_{π'} exp(θ·φ(π')) （对全部 4140 个划分精确求和）

极⼤似然估计为凸问题，⽤ L-BFGS。

模型阶梯（特征 φ）


 编号      特征                                       含义

 A0      ⽆（均匀分布）                                  下界

 A1      k, k²                                    类别数，允许内部最优

 A2      A1 + conj_abs                            全部单元在 L_abs 下合取

 A3      A1 + conj_rel                            全部单元在 L_rel 下合取

 A4      A1 + DL_abs                              描述⻓度（绝对基底）
 A5   A1 + DL_rel                        描述⻓度（相对基底）

 A6   A1 + DL_all(λ)                     四特征语⾔，λ 扫描

 A7   A2–A6 中表现最好者 + P2, P3, P4          加⼊位置特征

 A8   A7 + 同类别数下的重要交互（仅在计划中预先列出者）        可选

  区间：谱系组整组 bootstrap（固定折外预测重抽 5000 次）。
  正则化：对 θ 加 L2，强度在内层谱系分组交叉验证中从 {0, 0.01, 0.1, 1} 选择；同时报告固定
  强度下的敏感性。
  权重：谱系组等权为主，语⾔等权与⽆权为敏感性。

⽬的：说明选 q 不是为了凑合取结果，⽽是在候选特征中具有可检验的优势。

3a 穷举候选第四特征

  候选 = 对⼋个单元的全部⼆分，共 2⁷ − 1 = 127 个。
  对每个候选 f，语⾔ L_f = {s, a, r, f} ：
     C_f = 4140 个划分中全部单元合取的个数（纯组合量，与数据⽆关）；

     N_f = 625 个严格划分系统中全部单元合取的个数（系统与谱系组两种⼝径）；

     富集度 E_f = (N_f/625) / (C_f/4140) 。

  另外⽤论⽂既有的随机参照（保持词项数与类别⼤⼩）计算 N_f 的参照分布，报告 N_f 的
  参照区间。
  检查： N_q 应为 625 − 22 = 603。
  输出：127 个特征的表；散点图（横轴 C_f/4140 ，纵轴 N_f/625 ，标注 q、a、r、s 与富集
  度最⾼的若⼲特征）；q 的排名。

3b 对称性分类

  全局性别互换 (s, r) → (¬s, ¬r) 把⼋个单元分成四个轨道。在该变换下不变的⼆分应只有 7 个

  报告 q 与这 7 个特征中其余者的 C_f 、 N_f 、 E_f 。该结果⽤于论证"q 是少数在性别互换
  下不变的关系特征之⼀"。
