# 经典约束、表示方式与当前模型的对照

核查日期：2026年10月15日。依据现有正式文献登记表中的实际TXT和PDF；页序从PDF文件第一页起算，包括JSTOR及机构封面。本表是新稿的理论依据，不把补充分析方案记作已获得结果。

来源完整性更正：C08的正式篇幅以PDF首页为准，为281—320。现有39页作者副本仅含281—319，缺320页参考文献，不能据此把正式书目末页改为319，也不能称该副本完整。已读281—285的具体论证可定位；补全候选及核验状态见[专门说明](../notes/revision_c08_completeness.md)。

`s`为参照者性别，`a`为相对年龄，`r`为所指者性别，`q=s⊕r`为相对性别。M0为三差异加性，M1加入相对性别差异，M2含三项差异及全部两两乘积；M3为28个类别对饱和，M4为拟议的条件结构模型。M0—M2的“加性”均指共享概率的logit尺度。

## 三、对新增分析的解释界限

1. **约束对象不同。** 严格划分中的合取性是词项外延的性质；logit加性是跨语言总体二元概率的函数限制。二者不是互斥、穷尽的理论选项，应分别报告再联系。
2. **最小对不是完整推导。** 某特征在四个最小对中改变两次，不保证两次都落在原文定义的同一个四类分支；同一特征也可能在两个不同一级分支各作三级区分。P2—P5需要同时保存作用域和合法推导，不能只凭计数命名层级。
3. **P6对应而不等同于P2—P4。** `Dr×E`等系数控制共同取值主项后描述总体概率差，P2—P4则是语言内部完整划分的方向。两种证据可以互补，系数不能直接当作经典假设的唯一检验。
4. **已有研究已处理部分问题。** A10、A11已有系统发育分析；B02已有语系随机截距并讨论条件特征；B04已有谱系回归及重叠类别。准确的新贡献须由“明确经典方向约束＋细类别条件编码＋统一测量比较＋跨组预测验证”的具体组合来界定。

所有P2—P5的正文出处统一写为“Kronenfeld（1974）总结的经典二级／三级区分假设”，定位491页。不引用未取得全文的A02，不把491页的总结与496—500页的修订混为一谈。
