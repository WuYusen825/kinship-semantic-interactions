# 数据测量复核：同形、类别展开与来源字段

本复核只核对既有数据库字段、既有描述结果与上游导出机制，没有生成新的 S2 共享结果统计或拟合模型。数据锁定为 Kinbank commit `925cc0e702ae5481cfe0088aaa0e69c3991000f3`。可逐条复查的记录 ID、字段及命令见 [测量字段核查记录](../notes/revision_measurement_fields.md)。

## 1. 共用形式测量的是哪一层关系

现有主分析比较同一资料 ID、同一标准亲属类别内的 `Form` 集合：仅执行 Unicode NFC 和空白规范化，再判定两个集合是否至少有一个完全相同的成员。NFC 合并同一字符的规范等价编码，不删除重音、声调、大小写，也不寻找词干或词素关系。因此，共用书面形式、共用词素和共用语义范畴是三个不同对象。

`hermano mayor` 与 `hermano menor` 作为完整字符串不同，但都出现 `hermano`；`hermano` 与 `hermana` 也并不因可能有共同词干而在现有清洗中合并。Kronenfeld（2006:216，PDF第15页）将英语不同词项、西班牙语词干与性别后缀、芳蒂语通称加修饰手段作比较，直接说明分析完整词、词素或修饰构式会产生不同的分类对象。该页已回到本地 PDF 提取核对，不能把完整形式的分布直接当作词素系统。

还须区分词形集合与划分。集合有交集的关系通常不具传递性：例如 `{x}`、`{x,y}`、`{y}` 的相邻集合有交集，首尾却没有；这只是操作定义的逻辑性质，不是本次新增的经验结果。每类单词形的子样本可以按相同词形构成严格划分，全部系统的词形交集关系则不能自动解释成严格范畴划分。

## 2. 法语：年龄代码与来源注释的粒度不同

`v_standardfrenchstan1290-meB-1` 的 `Value` 与 `Form` 都是 `ainé`，`Parameter_ID=meB`，即男性参照者的年长兄；但 `Comment` 为 `first born son`，`Source=clifford_french_2018`。女性参照者对应行 `v_standardfrenchstan1290-feB-1` 具有同样字段。年长姐条目 `v_standardfrenchstan1290-meZ-1`／`-feZ-1` 记录 `ainée`，注释为 `first born daughter`，来源却是 `diniz_os_1977`。

这些字段支持“数据库把带首生注释的形式置于年长兄／姐代码下”的描述。`first born` 与相对于参照者年长并非同一关系，现有字段不足以确定这是源材料用法、资料录入时的推广，还是错误。不能据此宣布法语具有与日语相同的年龄词汇化结构，也不能宣布原始说话者或编者录错。这里已经确认的是标准类别与注释之间存在需要核查的粒度差异。

较粗的 `mB/fB` 另有 `frère`，`mZ/fZ` 另有 `soeur`，例如 `v_standardfrenchstan1290-mB-1`、`-fB-1`、`-mZ-1`、`-fZ-1`；这些行均标 `diniz_os_1977`。同一来源的 `frère/soeur` 也出现在较细的年幼条目。原分析固定只取八个带年龄的类别，因而没有把粗类条目自动并入所有年龄类别。这是样本定义的结果，不是本次核查发现这些基本词在真实语言中仅限年幼者。

## 3. 西班牙语：细类与粗类来自不同来源

`v_standardspanishstan1288-meB-1`／`-myB-1` 分别记录 `hermano mayor`／`hermano menor`，年长姐／年幼姐相应为 `hermana mayor`／`hermana menor`；女性参照者的四行同样如此。八行来源均为 `blanco_stan1288_nodate`，注释中有 `TRAD LIT` 与相应英语释义。较粗的 `mB/fB` 则记录 `hermano`，`mZ/fZ` 记录 `hermana`，来源均为 `diniz_os_1977`。

因此，完整字符串的差别确实进入既有测量；但同一语言资料 ID 内同时合并了不同来源和不同粒度的记录。不能把粗类形式直接当作同一来源遗漏于细类的同义词，也不能在看到结果后自行把它补入八类。若要改变这种处理，必须作为新的测量规则，在协议中说明依据和范围。

计划中的按空格词元共享可以检验另一种书写层面的关系，但不是词素分析。它既可能因 `hermano` 判定两年龄项共用，也可能因为 `mayor` 或 `menor` 将性别不同的两个表达判为共用。由此得到的变化不能只解释为“恢复共同亲属词干”。该敏感性尚未在本复核中运行。

## 4. 普通话：空格不是描述性短语的判据

`v_mandarinchinamand1415-meB-1` 记录 `ge ge`，`Comment=哥哥`，`Source=Chen_2019`；年幼兄、年长姐、年幼姐分别为 `di di`、`jie jie`、`mei mei`，注释为弟弟、姐姐、妹妹。八个带年龄条目都已有这些字段。可观察的是重复转写单位与相应汉字注释；其中的空格不能据以把“哥哥”归为描述性短语。

既有 `forum_descriptives.json` 保存的数字为：目标类别词形集合成员合计 9,830 个，其中 960 个含空格，涉及179个系统。代码显示其计数单位是“语言×类别内去重后的词形集合成员”：相同拼写跨类别会重复进入该合计，因此不能称为“9,830种全球唯一词形”或“960种不同的描述短语”。这些数字也不能证明179个系统全都使用描述性短语。

普通话粗类 `mB/fB` 的 `xiong di` 注释为“兄弟”，`mZ/fZ` 的 `jie mei` 注释为“姐妹”，但 `Source` 为空。这些条目的存在不能自行补足细类来源，也不能因为粗类代码名为 brother/sister 就覆盖汉字注释所提示的解释问题。仅凭已有字段，粗类条目的准确指称与证据来源均应标为无法判断。

## 5. 粗类别展开有方法依据，但不能逐行反推

Passmore et al.（2023:7，PDF第7页）明确说明，源材料类别较粗时，编者将该词填入所有相关的细类别；其例子是把“父亲的兄弟”填入按年长／年幼及参照者性别细分的四格。这支持“数据库细格齐全不等于原来源对每格独立调查”的方法判断。

锁定版本的上游 `lexibank_kinbank.py` 逐行读取已经具有 `parameter` 的原始CSV，优先取 `ipa`，否则取 `word`，将来源与注释传入 CLDF；所读的导出代码中没有依据粗类代码自动生成八个兄弟姐妹细格的循环。`merge_collections.py` 主要合并既有各子项目文件。因此，论文说明的展开首先是采集／编码规则，不能仅凭导出阶段代码声称已逐行确定哪些记录经过展开。同一形式在多格重复、粗类与细类并存、或同一来源支持多个类别，本身都不足以证明具体一行由展开产生。

此外，`Form` 已经经过上游 `FormSpec` 处理，包括分隔符切分与括号内容剔除；本研究的 NFC 操作发生在此之后。应保留 `Value` 以追踪上游处理，但 CLDF 的 `Value` 也不一定等于尚未转写的原始文献字符串。

## 6. 来源字段能支持什么

`Source` 是对 `sources.bib` 的链接，不是独立的语义可靠性认证。法语的年长兄与年长姐分别链接不同来源；西班牙语细类和粗类也链接不同来源；普通话部分粗类没有来源。上述情况能确认为资料组织或来源完整性的差异，尚不能断言是引文误配或语义错误。Diniz 的书名涉及亚美尼亚语，并不单凭书名排除其中有比较性词表；原书未核对前应保留判断。

还应避免误读注释中的数字。西班牙语注释 `[398]` 对应上游 `source_raw=IE398` 和该来源的 `IE398` 关键词；粗类注释 `[80]` 对应 `source_raw=IE80`。这些标识不能未经核对就写成“原文第398页／第80页”。普通话 `source_raw=1238` 也只是一项原始来源字段，不能单靠数字形式确认其页码含义。

冻结 `results.json` 已记录多来源与无来源的质量计数，以及同一文献支持的共用词形情况；本复核没有重算这些统计，也没有把来源字段的缺失自动改记成不共用。新稿若需要这些数字，应直接引用其既有JSON键并说明分母。

## 7. 违例抽查的字段级判据（供S2协议采用，尚未执行）

至少20个违例系统的检查应发生在合取定义经作者决定、S2协议已提交并产生违例清单之后。抽查单位须为不同记录系统；同一系统违反多条预测仍只算一个。建议按P1–P5轮流取 Glottocode 排序后的系统、每轮去重，直至达到20个；若某类不足，从其他类补足。全部违例少于20个时检查全部并报告真实数量，不能补造案例。这种可复查的选取用于查错，不能估计全部违例的原因比例。

| 核查类别 | 可以直接记录的证据 | 不得据此作出的判断 |
|---|---|---|
| 数据库编码下的形式违例 | 既定程序给出违反某条P的模式；可定位所有原始行ID、Value、Form、注释与来源；该模式在固定规则下可重建 | 不能直接称“真实语义违例”或推翻心理表征假说 |
| 多单位转写／描述性表达线索 | 原始形式含空格、重复单位，或注释明确标 `TRAD LIT` 等；分别保留这几种字段事实 | 空格不等于短语；`ge ge` 不因空格被归为描述性表达；不能凭熟悉语言进行全库人工词素标注 |
| 较粗类别展开线索 | 注释明确记载复制／推广，或能追到所用上游规则及对应原行；分别记为“明确记录”与“仅有线索” | 仅有重复形式、同一来源、八类齐全时，不能确定已展开，更不能自动改写结果 |
| 来源／转写差异线索 | 同一对应位置有不同来源、Value与Form处理差异、空来源、或已标注的异写 | 不同字符串不自动是同一词的异写；同源字段不自动保证原文同页；不能擅自纠音、去词缀或并词 |
| 无法判断 | 缺源、原文未取得、注释不足、粒度冲突未解释、同形与同义无法区分、处理来源不可追踪 | 不以“未发现录入问题”替代“已确认真实语义反例” |

这些类别允许多选，另设一个总评字段；证据不足时总评必须为“无法判断”。本范围只复核已有字段，不能确认“真实语义违例”。抽查表至少保存：抽查序号、P编号、Glottocode、Language_ID、谱系、全部有关记录ID、Value、Form、Comment、原始Source、解析Source、资料页码状态、各线索标签、总评、理由和核查者。语义判定若需要原始民族志、词典上下文或母语者信息，应单列为后续任务，不在本次抽查中补造。

## 8. 可用于论文的测量表述

“精确同形反映的是数据库中记录形式的分布。西班牙语细分条目使用 `hermano mayor/menor`，较粗条目另记 `hermano`，两组来自不同来源；法语年长条目还带有 `first born` 注释，与相对年龄代码的粒度并不完全对应。含空格的记录同时包括普通话 `ge ge` 一类叠写，因而空格不能直接视为描述性短语的指标。细网格展开与来源转写也可能影响形式关系，须通过测量敏感性与逐行来源核查界定结论。”

上述表述不包含任何尚未执行的S2结果。来源登记中的原始资料只在这里作为数据库溯源键使用；未取得全文的原始资料，不因此获得新稿正式文献引用资格。
