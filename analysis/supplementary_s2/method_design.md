# S2 运行前的方法定义与实现建议

本文件供 S2 协议整合使用。它写于冻结分析、S1 结果及审稿人核查结论已知之后，属于事后补充分析的方法设计。本文档未读取 S2 共享结果；配套 `design_rank.py` 仅枚举八个抽象类别，不读取任何数据文件。读取共享结果的 S2 程序须在协议独立提交之后编写、执行。冻结协议、分析和 S1 均保留原样。

## 1. 条件结构模型的精确定义

八类按 `meB, myB, meZ, myZ, feB, fyB, feZ, fyZ` 排列。对单个类别定义：参照者性别 `s=0/1` 对应男／女，年龄 `a=0/1` 对应年长／年幼，所指者性别 `r=0/1` 对应男／女；相对性别 `q=s XOR r`，0 表示同性，1 表示异性。一个系统内的不同类别构成 28 个无序对。

对类别对 `i,j` 定义：

\[
D_r=1[r_i\ne r_j],\quad D_a=1[a_i\ne a_j],\quad D_e=1[s_i\ne s_j].
\]

共同状态列为：

\[
E=1[a_i=a_j=0],\ B=1[r_i=r_j=0],\
S=1[q_i=q_j=0],\ M=1[s_i=s_j=0].
\]

`S` 表示两个端点各自都是同性兄弟姐妹，不是“两个端点具有相同的相对性别”：两端都异性时 `S=0`。所有列对端点交换不变。`DrE=Dr×E`、`DaB=Da×B`、`DaS=Da×S`。

\[
\eta_{M4}=\eta_{M2}+\alpha_E E+\alpha_B B+\alpha_S S+\alpha_M M
 +\delta_2 D_rE+\delta_3 D_aB+\delta_4 D_aS.
\]

三项预期方向均为负。三项系数是共同状态主效应及其他列控制后的 logit 条件对比，不是原始共享概率差。例如，在其他状态对应的同龄异性所指类别对中，年长对减去年幼对的 logit 差为 `αE+δ2`，不能将 `δ2` 单独解释为该原始差。P2–P4 的系统层级计数与这些总体模型系数是两个分析层次。

## 2. 精确秩、嵌套和列处理

`design_rank.py` 使用 Python 标准库的有理数消元，得出：

| 模型 | 列 | 精确秩 |
|---|---|---:|
| M0 | 截距、Dr、Da、De | 4 |
| M1 | M0 加 Dr XOR De | 5 |
| M2 | M0 加 DrDa、DrDe、DaDe | 7 |
| M3 | 28 个类别对的独热编码，不另加截距 | 28 |
| M4 | M2 加 E、B、S、M、DrE、DaB、DaS | 14 |

M4 按上述列序逐列均增秩；实际不删除任何列。`rank([M3,M4])=28`，故 `M2 ⊊ M4 ⊊ M3`，两次维数增加分别为 7 和 14。M4 对 28 对尚未饱和。

预置冗余列删除顺序为 `M → DrE → DaB → DaS → E → B → S`，只删除不会降低当前秩的冗余列，保护 M2 核心列，并保持 `DrE` 需要 `E`、`DaB` 需要 `B`、`DaS` 需要 `S` 的主效应层级原则。该规则仅处理确切别名，不依据结果或系数方向选择列。D1–D5 均保留完整八类系统，每个非空训练样本都有同样的 28 对支持，理论上应始终保持 M4 秩 14。实际秩变化应记录为数据或实现差异，不能静默改为另一模型。

M4 编码选定的条件位置差异，却没有强制合取类别、特征决策树或传递性；M4 的预测优势本身不等于经典合取—层级理论整体得到验证。P1–P5 由划分层面分析回答。M0 的“加性”和所有乘积项的“交互”均限定在 logit 尺度。

## 3. 训练权重与评分权重分开定义

令训练集有 `N_T` 个系统、`G_T` 个谱系组，组 g 含 `n_g,T` 个训练系统，每个系统有 `m_l=28` 对。训练权重：

\[
w^{L}_{l,ij}=1/m_l,\qquad
w^{F}_{l,ij}=N_T/(G_T n_{g,T}m_l).
\]

两种训练权重总量均为 `N_T`。谱系等权时每组总量 `N_T/G_T`，组内系统等权；语言等权时每系统总量 1。所有计数只由当前训练集计算。保留相同总量，使 C=1 的有效惩罚强度在两种加权间可比较。直接把每个谱系组总量设为 1 会把总量变成 `G_T`，并改变 C=1 和 Firth 校正相对于工作似然的强度，故不采用。

对已完成的折外预测先求每系统平均损失 `L_l`。报告：

\[
L_L=N^{-1}\sum_lL_l,\qquad
L_F=G^{-1}\sum_g n_g^{-1}\sum_{l\in g}L_l.
\]

主结果是谱系等权训练、谱系等权评分；语言等权训练、语言等权评分并报。建议每组训练结果同时输出两种评分，便于区分“训练目标改变”与“评价目标改变”，但不因此增加训练设定。对全部折外预测一次性汇总评分，不先对大小不同的测试折等权平均。

该主加权决定作出时，谱系等权增益较大的审稿人核查结果已知；此事实须保留在协议和论文方法中。

## 4. 无惩罚 MLE、分离判定与 Firth 替代

主估计最大化加权二项工作似然：

\[
\ell(\beta)=\sum_iw_i\{y_ix_i^\top\beta-\log(1+e^{x_i^\top\beta})\}.
\]

一个系统的 28 对存在依赖，故这不是声称观测独立的完整系统生成似然。无惩罚 MLE 用于估计预测函数；区间采用谱系整组自助而非普通逐对独立标准误。

分离检查在每个实际训练样本及系数自助样本分别进行。可先按抽象类别对聚合加权成功数 `s_t` 和总量 `t_t`。若 28 个单元均有正、负结果且设计满秩，这是不存在分离的充分条件；否则用线性规划检查，而非仅凭优化器是否报告收敛判断。

具体线性规划：对每个有正例的设计行放入 `+x_t`，有负例的放入 `−x_t`，得到 A。约束 `Av≥0`、每个 `v_j∈[−1,1]`，最大化 `1ᵀAv`。最优值大于 `1e−8` 表示完全或准完全分离；混合单元自然同时产生 `+x_t` 和 `−x_t` 约束。保存最优值和求解状态。

MLE 使用稳定的 `logaddexp`／`expit` 计算，最大迭代 5,000，保存优化状态及每总权重标准化的最大绝对得分；目标阈值 `1e−8`。以下任一条件启动 Firth 替代：检出分离、MLE 无有限解／不收敛、参数或目标非有限、标准化得分未达阈值。不得因某个理论系数的符号而切换估计器。

Firth 替代采用：

\[
\ell_F(\beta)=\ell(\beta)+\tfrac12\log|I(\beta)|,
\quad I=X^\top\operatorname{diag}(w_ip_i(1-p_i))X.
\]

可用调整得分 `Xᵀ{w(y−p)+h(1/2−p)}`，其中 `h_i=w_ip_i(1−p_i)x_iᵀI⁻¹x_i`；用阻尼 Newton 与增益线搜索求解，并检查惩罚目标、得分和有限参数。Firth 以全零系数为初值，最多 10,000 次迭代；收敛阈值同样为调整得分最大绝对值除以总权重不超过 `1e−8`，并要求目标与系数有限、信息矩阵可正定分解。每步先计算 `I⁻¹U_F`，按 1、1/2、1/4 等最多 40 次减半线搜索，接受惩罚目标不下降（绝对舍入容差 `1e−12`）的步长。未达到得分阈值且线搜索失败即记失败，不以很小步长本身宣称收敛；不静默给信息矩阵添加 ridge 项。这里是在预先规定的非整数加权工作似然上采用 Firth 型 Jeffreys 校正，不把独立整数 Bernoulli 模型中的偏差性质直接移作本研究的保证。权重总量须按第 3、8 节固定。

每次拟合记录 `MLE/Firth`、触发原因、收敛、秩、得分、极端预测和迭代数；若 Firth 亦失败，保存该预设拟合为失败，不改换未经协议指定的 ridge 值。报告每种设定采用 Firth 的折数；5000 次系数重拟合另报采用比例与最终有效比例。不要默默丢弃失败重抽样或无限追加直至获得 5000 个成功样本。

## 5. C=1 衔接与模型参数化

衔接参照仍用现有 scikit-learn `LogisticRegression`、`lbfgs`、`tol=1e−9`、`max_iter=5000`，截距不惩罚，使用第 3 节权重。M0、M1、M2 的 D1／语言等权训练／语系折／C=1 必须逐项重现冻结评分，容差 `1e−9`。

M1 保留相对性别编码。M4 的 13 个非截距系数受同一 L2 惩罚，不进行数据驱动列标准化；C=1 下不同编码的惩罚几何仍属于该参照的定义。M3 无惩罚时使用 28 独热列且无截距；C=1 时如需与 S1 完全衔接，应保持 S1 的 28 独热列加不惩罚截距的参数化，说明其函数空间秩为 28。M3 的系数不作语义解释。

## 6. 三种验证目标与折定义

1. **语系五折**：沿用冻结 D1 的逐系统测试折；对 D3、D4 子样本沿用剩余系统原折号。测试谱系不得出现在该折训练集。此定义避免子样本变化同时改变分折成为额外因素。
2. **留一宏观区域**：Macroarea 按分号第一值归类，预定六个值为 Africa、Australia、Eurasia、North America、Papunesia、South America。每次一个区域全体留出。相同谱系可能跨区域进入训练和测试，这是地域推广目标，不称为同时跨谱系与地域的双重隔离。缺少区域的系统只从这项地域验证排除并逐项记录，不改变其他验证样本。
3. **语言五折**：先在完整 D1 按 Glottocode 确定五折，再对子样本沿用原折号；同系统不得跨折。相关谱系可同时出现在两边，此项只作参照。

冻结语系折通过与 `oof_predictions.csv` 的主条件按系统和类别对联结逐项核验；折号及每折系统／谱系／区域数写入 `s2_fold_info.csv`。主分组和语言分组不得根据结果重新分配。任何模型、估计器、测量定义和训练权重共享相同对象的测试折。

## 7. 完整交叉稳健性与比较集合

D1 至少共一完整词形；D2 词形集合完全相等；D3 每类一词形的系统中沿用 D1；D4 删除任何目标类别含空格形式的系统后沿用 D1；D5 先按空白切分所有形式、类别内取词元并集，再判定两类词元集合交集非空。D5 保存词元化改变形式数、涉及系统数，以及相对 D1 真正改变二元结果的对数与系统数，区分这几个口径。所有 D 仍包含每个纳入系统的全部八类与 28 对。

完整网格为 `5测量×2估计(MLE及其Firth替代/C=1)×2训练权重=20` 个设定，每个运行三种验证、五个模型，共 300 个“设定×验证×模型”评分块。两种五折和六个区域折对应每个设定 80 次折内模型拟合，共 1,600 次，实际区域缺失等情况另记。此数不含冻结复现、全样本系数、自助与 GLMM。

每块均报告以下七个基准减比较模型的损失差：`M0−M2、M1−M2、M0−M1、M0−M4、M2−M4、M2−M3、M4−M3`。主表示比较为 M0−M4 与 M2−M4。所有对比及全部设定均输出，不按区间或方向筛选。

## 8. 两种自助区间严格区分

### 8.1 固定折外预测的评分区间

每个设定、验证与比较使用已保存的逐系统损失差 `d_l`，对 G 个谱系组有放回抽 G 次，5000 次，`default_rng(20261014)`。令抽中次数为 `k_g`，主谱系等权重抽样值为：

\[
\Delta_F^{(b)}=G^{-1}\sum_gk_g\bar d_g.
\]

语言等权值为 `Σ_g k_g Σ_{l∈g}d_l / Σ_g k_g n_g`。两者都保存 2.5%、97.5% 百分位区间；相同样本的模型比较共享抽样索引。这里不重训、不重新分折，只反映固定预测下的谱系组成变化，不能写为包含完整估计过程的区间。

### 8.2 主条件 M4 系数的重拟合区间

限 D1／无惩罚及预置 Firth 替代／谱系等权训练的全样本 M4。抽样单位仍为谱系组，G 次整组有放回抽样，5000 次、同一固定种子；每次重新估计全部 14 个系数，保存三个理论条件项及全部拟合诊断。

各组原有 `n_g` 不变，抽中次数 `k_g`；原始各对权重为：

\[
w_{l,ij}^{(b)}=k_g N/(G n_g\times28).
\]

每次总权重固定 N。重复抽中的谱系视为多次组抽样，不能合并成唯一组后又给每个唯一组相同权重，那样会抹去 `k_g`。实现时允许用乘数聚合，不需复制整张原始表。Firth 校正按同一固定总量定义，避免自助样本的总量变化额外改变校正强度。

该区间包含全样本条件项估计对谱系抽样的变动，不是 CV 预测增益区间，也不包含重新分折。若另外输出语言等权重拟合，则每对权重为 `k_g/28`，总量为抽到的系统数 `Σk_g n_g`；不可混称相同的权重尺度。主规定不要求另外的语言等权系数重拟合。

三个理论项分别报告点估计、谱系簇重拟合 95% 百分位区间及负值比例。95% 区间上界小于零时记为方向与预测相符且该逐项区间支持；区间跨零记为方向证据未定；下界大于零记为方向相反。三个区间是逐项区间。P6 的整体判定要求所有必要条件同时满足，采用交并判断：两个主谱系预测增益区间均高于零、三个系数区间均低于零。不能从五项中的某一项通过就宣称整条预测通过，也不将逐项结果写为同时置信覆盖整个系数集合。

各区域的条件项符号限定为 D1／MLE及Firth替代／谱系等权的区域内全样本 M4；各区域重新以其 `N_a,G_a,n_g,a` 构造训练权重，总量为 `N_a`，不简单截取全样本权重。保存三个条件项、实际有效谱系数和估计器；不另做每区域 5000 次系数重拟合。

## 9. 可大幅减轻计算的精确聚合

所有模型仅由 28 种类别对决定预测。因此可将训练资料聚合为每种类别对的加权成功数及暴露总量，28 行足够计算原加权目标、梯度和 Hessian。这是计算上的精确等价，不把系统内类别对视为独立的统计推断单元。

在主完整 D1 系数自助中，预存各谱系组、各类别对的共享均值 `q_g,t`。每次抽样后：

\[
s_t^{(b)}=\frac{N}{28G}\sum_gk_gq_{g,t},\qquad t_t^{(b)}=N/28.
\]

据此在 28 行上拟合 14 参数即可，避免 5000 次重复复制 26,292 行。先在小量非结果导向的数值核验中确认聚合与逐行目标、梯度及概率一致，再全量执行。无惩罚 M2 的单元拟合等于相应权重下七差异单元共享率；无惩罚 M3 等于 28 类别对共享率，这两项可作为独立核验；Firth 替代不再要求与原比例严格一致。

## 10. GLMM 能力核查与明确选择

运行前环境核查：最初无 statsmodels 和 Rscript；root 安装后 `statsmodels 0.15.0` 的 `BinomialBayesMixedGLM` 已成功导入，构造函数和 `fit_vb` 可用。不存在 `sample_weight` 参数，故该模型不模拟主要谱系等权训练。

协议建议固定：D1 全样本、原始逐对二元结果、未加权、M0/M2/M4 三模型；随机截距为谱系与第一个宏观区域：

\[
\operatorname{logit}p_{l,ij}=x_{ij}^{\top}\beta+u_{g(l)}+v_{a(l)},
\quad u_g\sim N(0,\sigma_g^2),\quad v_a\sim N(0,\sigma_a^2).
\]

使用 `BinomialBayesMixedGLM.from_formula`，`vc_formulas={'family':'0+C(family_group)','area':'0+C(area_primary)'}`；`fe_p=2`、`vcp_p=0.5`，即固定效应先验标准差 2，随机标准差对数的先验标准差 0.5。所有模型使用相同参数化、先验与数据范围。

用均值全零、后验初始标准差全为 `exp(−0.5)` 的确定性初值，`fit_vb(fit_method='BFGS', minim_opts={'maxiter':2000,'gtol':1e−6}, scale_fe=False, rng=20261014)`。保存近似后验均值、标准差、正态近似 95% 区间、随机截距尺度、ELBO、优化状态、梯度范数及警告。若未收敛，按同一初值与算法仅将最大迭代增至 10,000 重试一次，并完整记录。近似区间称为变分后验区间，不称为谱系自助置信区间。

此选择遵循计划指定的两个随机项。仅加谱系和区域截距仍未单独表示同一语言内部共享节点的相关性；它是未加权、模型化的独立敏感性，不能宣称已充分消除全部语言内依赖。变分近似与仅六个区域的尺度先验也影响其区间。不得把这三个全样本拟合的区间或拟合目标冒充三种 CV 下的主要预测证据。加入第三个语言截距属于另一明确的模型扩展，不在本次已选两随机项中静默实施。

## 11. 效应量、校准和解释口径

除自然对数损失差外，保存每个系统的 28 对工作对数似然比和：

\[
R_l=\sum_{ij}(\log P_{alt}(y_{l,ij})-\log P_{base}(y_{l,ij}))=28d_l.
\]

这是依赖类别对的预测工作似然比，不是独立证据因子或整套系统联合概率的似然比。其语言等权／谱系等权汇总保持同样权重，并用相同固定预测自助索引换算区间。

对七种差异单元，以相同目标权重计算预测概率均值减实测共享比例的有符号校准差，另报绝对差、最大绝对差及按单元等权平均绝对差；完整系统中每单元恰四对。M4/M3 同一差异单元内四对概率可能不同，须先在该单元内按系统与目标权重平均，不取任意代表对。校准使用折外预测；全样本拟合校准另标为描述性。

## 12. 最低实现记录
