# 补充分析S1协议：嵌套调参、编码依赖与类别对层面结构

写定时间：2026年10月15日（UTC），在运行本补充分析的任何代码之前写定，并单独提交到 git；提交时间即本协议的时间证据。

## 地位与边界

本协议写于2026年10月14日冻结分析的结果已知之后，因此**不是事前协议**，结果只作补充分析报告，不替代冻结协议中的主比较（固定 `C=1`）。原 `protocol_frozen.md`、`results.json` 及其全部输出保持不变。本补充回应冻结分析留下的三个问题：

- Q4：固定 `C=1` 是外生选择。若惩罚强度在每个外层训练集内部按谱系分组的嵌套验证选择，三模型的跨语系比较结果如何？
- Q5：经典模型可写成 `Dr, Da, De, Dr XOR De`（相对性别编码），也可写成 `Dr, Da, De, Dr×De`（乘积编码）。二者未惩罚时函数空间相同。岭惩罚下两种编码的样本外损失相差多少？
- Q6：七差异单元模型对同一差异单元内的四个具体类别对给出相同预测。若为28种具体类别对各设一个参数，样本外预测还能改善多少？这一比较给出“类别对层面结构”可带来的预测增益上限。

## 数据与折

- 只使用主样本 `analysis/pairs_primary.csv`（939个系统、125个谱系组、26,292个类别对），共享结果、权重与冻结分析相同：每个训练语言内类别对权重之和为1。
- 外层折与冻结分析相同：按文件原有行序对 `family_group` 做确定性五折 `GroupKFold`。运行时核对每个类别对的外层折号与 `oof_predictions.csv` 中主分析（`variant=primary`，`cv_grouping=family`）的折号一致；不一致则停止。
- 内层：在每个外层训练集内部，再按 `family_group` 做确定性五折 `GroupKFold`。外层测试集不参与任何选择。

## 模型

| 代号 | 列（均含不惩罚截距） |
|---|---|
| M0 原始加性 | `Dr, Da, De` |
| M1 经典加性（相对性别编码） | `Dr, Da, De, Dr XOR De` |
| M1p 经典加性（乘积编码） | `Dr, Da, De, Dr×De` |
| M2 两两交互 | `Dr, Da, De, Dr×Da, Dr×De, Da×De` |
| M3 类别对饱和 | 28种无序类别对的完整独热编码 |

## 拟合与选择

- 固定效应 L2 岭 logistic 回归（scikit-learn `LogisticRegression`，`lbfgs`，`tol=1e-9`，`max_iter=5000`），与冻结分析的实现相同。
- 惩罚网格 `C ∈ {0.01, 0.1, 1, 10, 100, 1000}`。每个模型、每个外层折分别选择：取内层折外预测的语言等权对数损失最低的 `C`；并列时取较小的 `C`（较强惩罚）。随后用该 `C` 在整个外层训练集上重新拟合，预测外层测试集。
- 另报告所有模型在固定 `C=1` 下的外层结果。M0、M1、M2 在固定 `C=1` 下必须重现 `results.json` 的主分析损失（容差 `1e-9`）；不重现则停止。

## 评分与区间

- 主指标为语言等权对数损失，另报 Brier 分数；增益为基准损失减去比较模型损失，正值表示后者更好。
- 预先指定的比较（嵌套调参与固定 `C=1` 各报一次）：M0−M2、M1−M2、M0−M1、M1−M1p（编码差）、M2−M3（类别对层面增益）、M1−M3。
- 区间：对固定折外预测的语言损失差按谱系组整组抽样5,000次，随机种子 `20261014`，报百分位95%区间，与冻结分析一致；同样不包含重训和重新划折的不确定性，不报 p 值。另报最大谱系组（南岛语系）移除后的点估计以及正、负增益谱系组计数。
- 记录每个外层折各模型选中的 `C`、内层得分、收敛状态与设计秩。

## 解释规则

- 主结论仍以冻结的 `C=1` 比较为准。S1 若与主比较方向一致，表述为“对惩罚选择不敏感”；若不一致，如实报告并把结论限定为依赖估计设定。
- M2−M3 只说明七单元之外的类别对层面结构能带来多少样本外预测改善，不说明这些结构的来源（次级区分、数据库展开或来源差异），也不把 M3 的参数解释为语义特征。
- 不根据 S1 结果更改主样本、结果变量、模型集合或冻结协议的任何内容；S1 的全部预先指定比较都报告。
