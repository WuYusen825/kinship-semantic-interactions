# 亲属类别共享词形的预先固定分析协议

本协议在完成编码、覆盖率、设计矩阵秩与谱系字段结构审计后、生成共享词形结果和进行任何模型比较以前写定。冻结时间、文件校验值以及执行环境另存于 `provenance.json`。本次属于研究计划执行阶段的事前分析协议，未声称已在独立注册平台预注册。

## 研究对象与证据顺序

研究范围为跨语言亲属称谓的词汇分类；对象为兄弟姐妹的年龄、所指者性别与参照者性别组合；分析单位为一个语言资料来源内两个不同标准类别的无序对。首先使用 Kinbank 原始论文和版本化数据说明，再使用 Glottolog 官方分类，随后使用本协议下自动处理生成的结构审计与预测结果。该分析为描述性、预测性观察研究，不据此推断认知或交际因果机制。

Q1：包含两两交互的模型是否改善未见语系语言的预测？Q2：改善是否超过经典同／异性兄弟姐妹区分？Q3：语言等权、来源选择、同义词处理与覆盖率变化以后是否稳定？

## 数据、谱系与样本

- Kinbank 仓库锁定为 `925cc0e702ae5481cfe0088aaa0e69c3991000f3`，使用 `kinbank/cldf/forms.csv` 的 `Form` 字段；遵循当前仓库的 CC BY 4.0 许可，引用原数据库论文，并列明本次版本。
- Glottolog CLDF 锁定为 `072ca0d0410039fb8b779be8fc165bac575d2cda`；按 Glottocode 联结官方 `Family_ID`。明确记录为孤立语言的对象以其语言级 Glottocode 单独分组；无法联结或未分类的对象排除于谱系分组分析，并逐项列出。方言共享其所属语言／语系分组。
- 类别固定为 `meB, myB, meZ, myZ, feB, fyB, feZ, fyZ`，`m/f` 表示参照者性别，`e/y` 表示年长／年幼，`B/Z` 表示所指者男性／女性；不把词形相似度或人工判断加进编码。
- 同一 Glottocode 有多个语言资料 ID 时，选择有效类别数最多的 ID；并列时按 ID 字典顺序选取。来源选择只使用结构覆盖，不使用词形共享比例或预测结果，不合并不同 ID 的记录。
- 主样本要求 8 类齐全；覆盖敏感性要求至少 6 类（75%）。缺失类别不生成负例。主样本有完整覆盖时，每种语言产生 28 个无序类别对。

## 词形、同义词与来源

仅执行 Unicode NFC 与空白合并，保留大小写、变音符号、声调及语音符号；将数据库明示的空串、`?` 和 `-` 视为缺失；不对词形再次执行括号删除、分隔符切词或音系重写。数据库此前生成 `Form` 的括号与分词处理是上游处理，本研究保留原始 `Value` 以供检查。

每个类别的所有有效记录去重为词形集合。主结果为两个集合交集非空。严格敏感性改为两集合完全相等；另在每类恰有一个词形的完整语言子样本重复主比较。共享词形是数据库记录的同形关系，不直接等同于心理语义欠指明。

记录 `Source` 字段中的文献标识，将分号分隔的引文分别展开；方括号内的页码只在来源标识处理中移除。量化每个类别／语言的来源数。来源敏感性为每个已选语言 ID 选择覆盖类别最多的单一来源；并列时按来源标识排序；用该来源拥有的词形重新建集合，仅保留其 8 类齐全的语言。未附来源的记录不属于单来源敏感性。不得依据结果选择文献来源。

## 特征、可识别性与经典基准

差异列的固定顺序为所指者性别 `Dr`、相对年龄 `Da`、参照者性别 `De`。共有 7 种非零差异组合，`000` 不存在。

1. 原始加性模型：截距与 `Dr, Da, De`，设计秩为 4。
2. 经典加性模型：另加入同／异性关系差异 `Drelative = Dr XOR De`，设计秩为 5。
3. 两两交互模型：截距、三个差异主效应以及 `Dr×Da, Dr×De, Da×De`，设计秩为 7。

经典同／异性特征满足 `Drelative = Dr + De − 2DrDe`，所以所指者性别×参照者性别在此编码中也可以表示传统相对性别的主效应。本研究首先报告交互模型与原始加性的差值，再报告交互模型相对经典加性的剩余增益；只有第二个比较支持超越该经典区分的预测结论。

交互模型在 7 个差异单元上是饱和模型；它将同一差异组合的多个具体类别对合并，尚非整个 28 对的饱和模型。三阶交互与已有列线性相关，不另估计。祖辈 `mFF/mFM/mMF/mMM` 与父母的兄弟姐妹 `mFB/mFZ/mMB/mMZ` 的二维无序对仅作描述；其截距+两主效应已经覆盖 3 个差异单元，不能另识别交互。

## 拟合、交叉验证与不确定性

- 使用固定效应 L2 岭惩罚二项 logistic 回归；此轮不声称完成语言／语系随机截距 GLMM。主惩罚固定 `C=1`，截距不惩罚，最大迭代 2,000；不根据测试集选择参数、阈值、模型或特征。所有输入为预先定义的 0/1，无需数据驱动标准化。
- 每个训练语言内类别对权重和为 1。主评估对语言平均 log loss 再等权平均；辅报类别对等权结果及 Brier score。正增益定义为基准损失减去交互损失。
- 主验证为确定性的五折 `GroupKFold`，按官方语系／孤立语言组整组留出，防止同语系训练和测试混杂。辅验证按语言整组留出。保存每个对象的折号、逐对预测和训练／测试组数；每个模型仅在当前训练折拟合。
- 不使用测试语言或语系的结果来估计截距；固定效应模型直接预测新语系总体水平。语言分组辅助结果允许相关语系存在于两边，因此不能替代主验证。
- 对固定的样本外预测，先在每个语言内计算损失差，再整组抽样语系 5,000 次，随机种子 `20261014`，报告均值差的百分位 95% 区间。此区间描述现有样本外预测对谱系组成的不确定性，不包含重训／分折不确定性，不报告据此产生的独立样本 p 值。
- 如模型不收敛，记录事实并不解释系数；如某一训练折缺少差异单元，报告秩及样本量。记录实际矩阵秩、极端预测和各单元观察数；不对模型训练样本拟合程度作主要发现。

## 固定的敏感性分析与呈现

主样本运行三个模型；另运行 75% 覆盖、完全相同词形集合、每类别单词形、单一文献来源、`C=0.1` 与 `C=10`。每种变体均使用同一规则构造分组折和相同模型比较。报告语系等权的损失差以及最大语系的杠杆贡献作为辅助描述。各变体不以显著与否决定是否报告，不新增数据驱动交互项。

保存逐类别词形、无序配对、来源、结构统计、七单元共享比例、折外预测、系数与结果 JSON、中文执行报告和可导出图表。结论界定为此版本数据库的预测规律；完整字段可能来自数据库对原始较粗类别的展开，不能把八类覆盖直接解释为八次独立 elicitation。结果不将统计交互转化为特定认知机制，也不以未见增益断言没有语义交互。
