# Kinbank 实际执行结果

本次确实执行了锁定版本的数据清洗、无序配对、固定惩罚 logistic 回归、五折语系整组留出、语言整组留出和语系簇 bootstrap。分析协议在结果生成前冻结，脚本为 `analyze.py`。

## 样本与质量

锁定 Kinbank commit `925cc0e702ae5481cfe0088aaa0e69c3991000f3`，原表共 218,412 条词形记录、1,314 个语言资料 ID、1,342 个参数。兄弟姐妹目标八类拥有 12,537 条记录、1,208 个资料 ID。按 Glottocode 去重移除 98 个重复来源 ID，保留 1,110 个 Glottocode。

去重后八类齐全的记录系统为 941 个；排除 2 个未解决谱系分类的记录，主分析为 939 个语言／语言变体记录系统、125 个谱系组（孤立语言单列）、26,292 个无序类别对。样本含历史语言，不能解释为仅代表当代在世语言。原始 Family 空缺的 180 个已选资料 ID 经官方 Glottolog 补联，不把这些对象全部当作孤立语言。

NFC 与空白处理改变 798 条目标记录；数据库列出的缺失标记在目标记录中为 0 条。仅采用数据库既有 Form；其上游切词与括号处理并非本研究新增。原始粗类别可能被数据库展开至年龄和参照者性别较细类别，因此八类齐全不表示原文献独立调查八个区分。

已选 1110 个 ID 的 11,428 条目标记录中，80 条没有来源；133 个语言资料 ID、701 个类别含多个来源（类别最大 6 个来源）。主定义对同一 ID 的有效同义词取并集；单来源敏感性重新限定至结构覆盖最佳的一篇文献。

主样本 8,412 个共享类别对中，8,326 对至少有一个共享词形获得同一文献来源支持，86 对未获得这种支持；这后一数字同时包含跨来源形成的共享与来源字段缺失，不能全部解释为资料矛盾。

## 模型识别与主比较

原始加性、经典加性、两两交互设计秩依次为 4、5、7。七个非零差异单元均存在；两两交互在差异单元层面饱和。由于 `Drelative = Dr + De − 2DrDe`，性别×参照者性别的表示可直接对应传统同／异性兄弟姐妹区分；三阶交互无法独立估计。经典与单交互五列模型空间相同，岭惩罚下不同编码并不保证同样预测。

主模型为固定效应岭 logistic 回归、`C=1`，训练语言内总权重为 1；没有拟合或声称拟合 GLMM。语系五折留出严格阻断同一谱系组进入两边。正增益为基准 log loss 减去两两交互 log loss，单位为自然对数。

| 模型 | 语言等权 log loss | Brier score |
|---|---:|---:|
| 原始加性 | 0.581049 | 0.192943 |
| 经典加性 | 0.578468 | 0.192613 |
| 两两交互 | 0.576625 | 0.191835 |

原始加性→两两交互的平均增益为 **0.004423**，语系簇 bootstrap 95% 区间为 **[-0.000510, 0.008205]**。

经典加性→两两交互的剩余平均增益为 **0.001843**，95% 区间为 **[-0.000604, 0.006120]**。

置信区间基于已完成的折外预测，在谱系组层面抽样 5,000 次；不包含重新训练或更换划折的不确定性，也没有把类别对当作独立样本计算显著性。

按语系等权而非语言等权时，原始增益为 0.009393，经典剩余增益为 0.002315。最大组 `aust1307` 含 296 个主样本系统；在既有折外预测中移除该组后，两项增益依次为 0.002326 与 0.003862。这里仅改变评分样本，没有重训模型。

主方案的区间均包含零，不能据此认定两两交互在新语系上有稳定增益。严格词形集合与单词形子样本下，超过经典基准的点估计变为负；较弱惩罚及无惩罚的敏感性则显示较大正增益。由此得到的是依赖词形处理和惩罚强度的证据，而非已经确立的普遍规律；不能事后把正向的无惩罚分析替换成主检验。

本轮估计对象是合并语言系统之后、向新谱系推广的边际共享词形概率。即使每个语言内的条件 logit 都是加性的，混合不同截距／斜率也可能产生边际非加性。整组交叉验证检验跨谱系预测，不能单独判定典型语言内部的语义表征需要交互；若要回答该问题，须另构造具有充分变异的分层或完整类别划分模型。

## 核验与证据台账

全部 135 次折内模型拟合的收敛状态为 True；最低训练矩阵秩保持 4、5、7。无惩罚七单元饱和全样本预测与实际共享比例的最大误差为 1.15e-09，符合其饱和性质。脚本验证每折没有同谱系／同 Glottocode 泄漏。

范围与对象限定：删去未解决谱系的两个对象；将二维扩展限定为描述；没有新增人工语义标注。所有计划敏感性均报告。主要预测结论仅适用于本次版本、来源选择、同形操作定义和新谱系评分方式；谱系分组不控制地理接触，语言内类别对相关性也没有被生成式划分模型直接表示。

未解决事项：语系与区域采样偏倚、上游粗类别展开、跨来源语体变体与偶然同形、真正心理语义表征、类别划分的传递性约束。当前数据支持预测关系，不能独立鉴别这些机制。
